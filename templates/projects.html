Smart Vending Machine

Smart Vending Machine is a project that uses a microcontroller to control the vending machine. It has a user interface that allows users to select the product they want to buy and pay for it using a credit card. The microcontroller also has a sensor that detects the weight of the product and calculates the price accordingly.In this smart vending machine we use different payment methods like UPI,cash,credit card,debit card.

Resume Maker

Resume Maker is a project that allows users to create a resume in a few simple steps. It has a user interface that allows users to input their personal details, work experience, education, and skills. The system then generates a resume based on the input provided by the user and also provides a feature to download the resume in PDF format.The system also provides a feature to save the resume in the database for future reference.
